# 太空工坊 Orbitwright

给孩子的离线二维火箭游戏。在工坊里把零件拼上青芽星的火箭，加油、转向、分离、开伞，再轻轻落地。

这是原创玩法，不是任何商业飞行游戏的复刻。数值、物理和大部分画面都是新写的。生成图片的来源写在 `PROVENANCE.md`。

网页版对应 Origin 草稿 `187321764bafc67e6c792220cbf0f509924dbabb`（1.7.0 / versionCode 23 的网页源码）。这个公开仓库只用来在 GitHub Pages 上玩，不包含 Android 工程、签名证书或出包脚本。

## 在浏览器里玩

合并到 `main` 之后打开：

<https://dannywang0822.github.io/orbitwright/?v=4>

`?v=4` 用来避开 2026-11-07 那版旧页面的缓存。站点是项目页 `/orbitwright/`。Vite `base` 是相对路径 `./`，构建成单文件后，脚本、样式和零件图都内嵌在 `index.html` 里，不会去请求站点根以外的路径。

页面一旦载入完成就可以离线玩，飞行过程不访问网络。

本地：

```bash
npm install
npm test
npm run dev
```

浏览器打开 <http://127.0.0.1:43127>。`npm run dev` 使用源码入口 `index.source.html`。

```bash
npm run build
npm run preview
```

`npm run build` 先跑 `tsc --noEmit && vite build`，再把 `dist/index.html` 复制到仓库根目录的 `index.html`。GitHub Pages 和 Leap On、旧 Orbitwright 一样，从 `main` 分支的 `/` 发布这个静态文件。不要直接双击源码入口 `index.source.html`。构建后的 `index.html` 可以当静态页打开。

## 怎么玩

- 点零件，再点格子。要挨着拼，先放指挥舱。
- 「可以发射」变绿再起飞。示例箭一定能飞。
- 右边是油门，底部两个键按住左转或右转，松开就停。
- 「稳住」默认开着：松开转向时，火箭不再自己乱转。这是阻尼，不是自动飞到月球。
- 分离环把下面一级推开。燃料不会穿过分离环。
- 回到空气里、速度不太快时开伞。落地大约要比每秒 5–6 米更慢，并且火箭大体竖直。
- 重试一键回到发射架，燃料加满。
- 记录只留在这台设备上（火箭图纸、任务星星、简单模式和声音）。「清除记录」会删掉它们。声音默认关闭。

任务：飞过 400 米，飞过 1200 米再安全落地，以及让近地点和远地点都离开大气层。最后一项要自己转一个弯。

触控和鼠标都能用。按钮至少约 56px，飞行摇杆跟着手指走。

## 数值

和 Spaceflight Simulator 1.6.00.22 的差异在 `docs/与原版差异清单.md`。已经收进源码、可以公开的数值表在 `docs/原版数值表.md`。已确认的提取值在 `src/sim/confirmed.ts`，估计值在 `src/sim/estimates.ts`。估计值不会被当成已提取值。原版安装包、贴图、音频和解包目录不在这个仓库里。

## 现在没有的东西

- 没有登月庆祝
- 没有热和动压解体
- 时间加速只有 1、2、5 倍，喷火或快速下落时不会生效
- 简单模式推力稍大、空气稍小、转向更稳、落地稍宽容。加速能力（Δv）和普通模式一样
