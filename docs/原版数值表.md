# Spaceflight Simulator 1.6.00.22 原版数值表（离线静态提取）

- 输入：用户提供的 XAPK（本机 /home/box/.../space61cc7b2.xapk），包名 com.StefMorojna.SpaceflightSimulator，Unity 6000.1.17f1，IL2CPP（metadata v31.1）。
- 提取时间：2026-11-09（北京时间）。没有运行目标 app，没有联网上传任何原版文件。
- 标注：**实测**＝直接从序列化资源读出的原值；**推断**＝由实测值按公式算出，或按字段名推测的语义；**平衡估计**＝原版里没有这个值，为我们的游戏建议的取值。
- 来源路径：`TA:` 指 Unity TextAsset（UnityPy 读出，对应 AssetRipper 导出的 `Assets/Resources/planet_data/<名>.txt|json`）；`P:` 指 AssetRipper 导出的 prefab `Assets/Resources/parts/...prefab`；`S:` 指场景 `Assets/Scenes/Mobile/...unity`。
- 单位：原版用米、秒，质量单位显示为 t（吨）。推力字段很可能是“吨力”（运行时 ×9.8），这一点属于**推断**，换算公式在代码里，还没核实。
